# 🖱️ Mouse God Mode & Window Flow (AutoHotkey v2)

> **把鼠标侧键变成平铺桌面的“离合器”，让手掌彻底接管 Windows 窗口与工作流。**

这是一套经过长期高强度实操迭代、高度稳定且“零误触”的 Windows 效率增强脚本。通过将鼠标前进/后退侧键升级为 **修饰层（Modifier Layer）**，配合平铺窗口管理器（如 GlazeWM）与多标签页应用，实现双手几乎不离鼠标/键盘即可完成毫秒级窗口调度。

---

## ✨ 为什么你需要这套配置？（痛点与爽点）

* ⚡ **平铺窗口无缝流转**：按住后退键滚轮一滑切工作区，左右拨动滚轮推移窗口。平铺桌面不再只能靠别扭的键盘快捷键，单手刷网页时依然掌控全场。
* 🎯 **彻底告别精准瞄准**：关窗口、最大化还要把光标费劲移到右上角那颗小叉叉？前进键 + 滚轮一偏直接带走，效率翻倍。
* 📑 **全局极速切标签页（Tab Shifter）**：按住右键滚轮上下滑动即切换多标签，左右拨动新建/关闭，支持浏览器、终端、编辑器等全系生产力工具。
* 🛡️ **内置防抖限流与高权限保活**：解决了 AHK 常见的“滚轮一滑连续触发50次Tab报警”与卡顿挂起问题，原生配置低延迟限流，如丝般顺滑。
* 🚀 **核心应用快速拉起/召回**：Win 键绑定后台常驻应用，支持托盘隐藏应用温和唤醒与优雅退出。

## ⌨️ 核心热键与手势映射

### 1. 鼠标前进键（XButton2）— 窗口控制层

| 组合手势 | 功能说明 | 适用场景 |
| :--- | :--- | :--- |
| **按住前进键 + 左键拖动** | 移动窗口（Alt + 拖动） | 快速挪动悬浮窗口 |
| **按住前进键 + 右键拖动** | 调整窗口大小 | 任意边缘/角落缩放 |
| **按住前进键 + 滚轮上下** | 极速切换窗口 (`Alt + Tab`) | 免键盘切换任务 |
| **按住前进键 + 滚轮向右** | 关闭当前窗口 (`WinClose`) | 秒杀右上角小红叉 |
| **按住前进键 + 滚轮向左** | 最大化当前活动窗口 | 快速全屏阅读/对比 |
| **按住前进键 + 鼠标中键** | 窗口状态切换（最大化 / 还原 / 最小化） | 单手三段式切换 |
| **单击前进键** | 浏览器默认前进 | 保持原生逻辑不破坏 |

---

### 2. 鼠标后退键（XButton1）— 平铺与工作区层（适配 GlazeWM）

| 组合手势 | 功能说明 | 适用场景 |
| :--- | :--- | :--- |
| **按住后退键 + 滚轮向上** | 切换到上一个工作区 (`Alt + S`) | 多屏幕/多工作区快速跳转 |
| **按住后退键 + 滚轮向下** | 切换到下一个工作区 (`Alt + A`) | 紧凑切换工作环境 |
| **按住后退键 + 滚轮向左** | GlazeWM 窗口左移 (`Alt + Shift + Left`) | 调整平铺布局分块 |
| **按住后退键 + 滚轮向右** | GlazeWM 窗口右移 (`Alt + Shift + Right`) | 调整平铺布局分块 |
| **按住后退键 + 鼠标中键** | 刷新当前页面 / 界面 (`F5` / `Ctrl + R`) | 单手刷新网页或 AI 客户端 |
| **单击后退键** | 浏览器默认后退 | 保持原生逻辑不破坏 |

---

### 3. 右键滚轮增强（Tab / 滚动手势）

> 在多标签应用中（浏览器、VS Code、Windows Terminal、Obsidian、PDF 阅读器等），**按住鼠标右键**即可进入标签控制模式：

* **右键 + 滚轮上/下**：向前 / 向后切换 Tab（`Ctrl + Shift + Tab` / `Ctrl + Tab`）
* **右键 + 滚轮向左**：新建标签页（`Ctrl + T`）
* **右键 + 滚轮向右**：关闭标签页（`Ctrl + W`）
* *(QQ 专属优化)*：按住右键滚轮上下直接上下切换会话，左右拨动查记录与搜索。

### 4. 键盘启动器（App Manager）

| 快捷键 | 目标应用 | 操作说明 |
| :--- | :--- | :--- |
